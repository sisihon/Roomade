\# Roomade (룸메이드)



\*\*Team Halfway\*\*



Roomade는 룸메이트들이 공동생활에 필요한 물품을 관리하고 공유할 수 있도록 개발하는 Android 애플리케이션입니다. Android 앱과 Node.js 기반 백엔드 서버, MySQL 데이터베이스를 연동하는 구조로 개발하고 있습니다.



\## 🛠️ 개발 환경 및 기술 스택



\### 1. Android Application

\- \*\*Android Studio\*\*: Android 애플리케이션 개발 환경

\- \*\*Kotlin\*\*: 앱의 주요 기능 및 동작 로직 구현

\- \*\*XML\*\*: 화면 구성 및 사용자 인터페이스 설계

\- \*\*CameraX / ML Kit\*\*: 카메라 기반 QR 코드 및 바코드 인식 기능 구현에 활용



Android 애플리케이션은 사용자가 직접 이용하는 화면과 기능을 담당합니다. Kotlin으로 화면의 동작과 데이터 처리를 구현하고, XML을 활용하여 각 화면의 레이아웃을 구성합니다.



\### 2. Backend Server

\- \*\*Node.js\*\*: 백엔드 서버 실행 환경

\- \*\*Express\*\*: HTTP 요청을 처리하는 API 서버 구성



Node.js와 Express를 사용하여 Android 앱에서 전달하는 요청을 처리하고, 데이터베이스와 통신하는 서버 환경을 구성했습니다. 앱에서 상품 등록을 요청하면 서버가 해당 요청을 처리하고 데이터베이스에 저장하도록 연결했습니다.



\### 3. Database

\- \*\*MySQL 8.0.16 이상\*\*

\- \*\*Database Name: `roomade`\*\*

\- \*\*SQL\*\*: 테이블 및 데이터베이스 구조 정의



MySQL을 이용하여 Roomade에서 사용하는 데이터를 관리합니다. `schema.sql`을 통해 데이터베이스와 테이블 구조를 정의하고, 기본키(PK), 외래키(FK) 및 제약조건을 구성하여 데이터 간의 관계와 무결성을 관리합니다.



\## ✨ 현재 구현 내용



\### 1. QR 코드 및 바코드 스캔 기능



사용자가 상품을 직접 검색하거나 입력하는 과정을 줄이기 위해 QR 코드 및 바코드를 인식하는 기능을 구현했습니다.



\- Android 카메라를 이용한 코드 스캔 기능

\- QR 코드 및 바코드 인식 처리

\- 스캔 결과를 활용한 상품 정보 조회

\- 조회된 상품 정보를 확인한 후 등록하는 과정 구성



카메라를 통해 인식한 코드를 기반으로 상품 정보를 조회할 수 있도록 구성했습니다. 이를 통해 사용자가 상품명을 일일이 입력해야 하는 번거로움을 줄이고, 물품 등록 과정을 간편하게 만드는 것을 목표로 합니다.



\### 2. 상품 정보 조회 및 물품 등록



스캔한 상품의 정보를 서버와 연동하여 조회하고, 확인된 상품을 데이터베이스에 등록하는 기능을 구현했습니다.



\- 스캔한 상품의 정보 조회

\- 조회된 상품명 확인

\- 상품 등록 요청 전송

\- 서버를 통한 데이터 처리

\- MySQL 데이터베이스 연동

\- 등록 요청에 대한 성공 응답 확인



사용자가 상품을 스캔하면 상품 정보를 확인하고 등록 요청을 진행할 수 있습니다. Android 앱에서 전달한 데이터는 Node.js 서버에서 처리하며, 서버는 MySQL 데이터베이스와 연동하여 물품 등록을 수행합니다.



\### 3. Android와 Node.js 서버 연동



Android 애플리케이션과 백엔드 서버가 서로 데이터를 주고받을 수 있도록 통신 환경을 구성했습니다.



\- Android 앱과 Node.js 서버 연결

\- Express 기반 API 요청 처리

\- HTTP 통신을 통한 데이터 전달

\- 서버 응답을 Android 앱에서 처리

\- 상품 등록 요청 및 성공 응답 확인



앱 내부에서 모든 데이터를 직접 처리하는 방식이 아니라, 별도의 서버를 통해 데이터를 처리하도록 구성했습니다. 이를 통해 향후 일정, 청소, 공동 물품 관리 등 다른 기능을 추가할 수 있는 기반을 마련했습니다.



\### 4. MySQL 데이터베이스 구축 및 연동



Roomade에서 사용할 데이터를 체계적으로 관리하기 위해 MySQL 데이터베이스를 구축했습니다.



\- `roomade` 데이터베이스 구성

\- `schema.sql`을 통한 테이블 생성 및 구조 정의

\- 테이블 간 기본키(PK) 및 외래키(FK) 설정

\- 데이터베이스 제약조건 구성

\- Node.js 서버와 MySQL 연결



데이터베이스 구조를 SQL 파일로 관리하여 팀원들이 동일한 데이터베이스 구조를 구성할 수 있도록 했습니다.



\### 5. Android 로컬 네트워크 통신 환경 설정



개발 과정에서 Android 앱이 로컬 네트워크에 있는 Node.js 서버와 통신할 수 있도록 관련 권한과 설정을 구성했습니다.



\- Android 로컬 네트워크 접근 권한 설정

\- Android 17 환경에 맞춘 네트워크 접근 설정

\- 개발용 서버와 앱 간 통신 확인



이를 통해 개발 환경에서 Android 앱이 별도로 실행되는 백엔드 서버에 요청을 전달할 수 있도록 했습니다.
